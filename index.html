마이크 확인 · 권한 도움말

권한 창은 Read 또는 마이크 확인을 눌렀을 때만 요청합니다.

  1. 컴퓨터에서 USB 마이크를 쓸 때: 위 ‘사용할 마이크’에서 그 마이크를 고르고 ‘마이크 확인’으로 막대가 움직이는지 보세요. Windows 설정 → 시스템 → 소리 → 입력에서도 같은 마이크를 고르고 음량을 올려 두면 더 확실해요.
  2. 배포한 HTTPS 주소를 Chrome 일반 탭에서 직접 열어 주세요. 파일 미리보기나 다른 앱 안의 화면에서는 제한될 수 있어요.
  3. 스마트패드 설정 → 애플리케이션 → Chrome → 권한 → 마이크에서 앱 사용 중에만 허용을 선택해 주세요.
  4. Chrome → 설정 → 사이트 설정 → 마이크에서 현재 사이트를 허용해 주세요. 기기 전체의 ‘마이크 액세스’도 켜져 있어야 해요.
  5. ‘음성인식의 마이크 접근이 차단’ 메시지가 나오면: 영어 음성인식은 Google 앱이 처리해요. 설정 → 애플리케이션 → Google → 권한 → 마이크를 앱 사용 중에만 허용으로 바꾸고, Play 스토어에서 Google 앱을 업데이트해 주세요. 그래도 안 되면 Chrome 주소창 왼쪽 아이콘 → 권한 → 권한 재설정 후 새로고침해서 다시 허용해 주세요.
  6. 마이크가 다른 앱에서 사용 중이면 그 앱을 닫아 주세요. 학교 관리 기기에서 설정이 잠겨 있으면 담당 선생님께 알려 주세요.

천천히 읽어도 괜찮아요. 중간에 잠깐 쉬어도 1분 동안 계속 들어요.
자동 확인은 영어 단어를 알아듣는 활동이며 전문 발음 점수는 아니에요. f/p, v/b, r/l, th/t처럼 헷갈리기 쉬운 발음과 a, the 같은 작은 단어는 너그럽게 인정해요.
